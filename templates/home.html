Fuel Management System

The Fuel Management System is a web-based application developed to digitally manage fuel purchases, fuel distribution, and vehicle-wise fuel consumption. This system replaces manual fuel logs and ensures accurate, transparent, and real-time fuel tracking.

The project is implemented using Python Flask for backend logic, SQLite as an offline database, and HTML & CSS for a modern user interface.

🔧 Project Type: College Major Project

⚙️ Technology: Python Flask, SQLite, HTML, CSS
